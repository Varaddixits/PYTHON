# Assignment 2

A collection of Python exercises covering order discounts, order lists, and daily sales totals.

## Files

- `GenAI_task(01).py` — Calculates a tiered discount and final price for one order, with numeric input validation.
- `GenAI_task(02).py` — Applies tiered discounts to a sample list of orders and prints an order summary.
- `GenAI_task(03).py` — Lets you add orders to a list and display calculated values for the saved orders.
- `GenAI_task(04).py` — Processes daily sales, skips zero values, stops at `-1`, and displays running and final totals.

## Run

Run a script with Python 3 from this folder. For example:

```bash
python "GenAI_task(01).py"
```

Each script runs independently.
