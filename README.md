# Python Assignments

A collection of beginner Python exercises covering lists, tuples, sets, dictionaries, loops, and basic data processing.

## Files

- `GenAI_task(01).py` — product lists, tuples, and basic collection operations
- `GenAI_task(02).py` — sets and category membership
- `GenAI_task(03).py` — dictionary updates, deletion, and average price calculation
- `GenAI_task(04).py` — building a product catalog and grouping products by category

## Run

Run a file with Python 3 from this folder, for example:

```bash
python "GenAI_task(01).py"
```

These are learning exercises, so each file runs independently.
